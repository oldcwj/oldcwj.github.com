MBOX File Viewer Help Center

Open, search, and export MBOX email archives privately on your iPhone or iPad.

About MBOX File Viewer

MBOX File Viewer reads MBOX email archives on your device. It does not require an email account, Gmail sign-in, cloud upload, IMAP, or POP3 connection. It is a viewer for archives, not an email client: it cannot send or receive mail.

MBOX is a common archive format used by Gmail Takeout, Thunderbird, Apple Mail exports, and other mail tools. An archive can contain one message or many years of email in a single file.

Open an MBOX Archive

  1. Save the archive to Files, iCloud Drive, or another available document provider.
  2. Open MBOX File Viewer and tap Open MBOX File.
  3. Select the archive in the file picker.
  4. Wait for the message list, then select a message to view it.

You can also use the iOS Share sheet or an “Open in” action from another app when MBOX File Viewer is available. The file does not need a .mbox filename extension; the app checks the archive content when it opens it.

Opening Large Archives

During the first scan, the app displays completion percentage, bytes scanned, total file size, messages found, and—when enough data is available—an estimated time remaining.

Archives are scanned in small chunks while the app creates a lightweight message index. It does not load the entire archive or every message body into memory at once. Tap Cancel to stop; a cancelled scan does not create a Recent Files entry or retain a partially opened mailbox.

Read Messages Safely

Select a message to view its headers, plain-text body, or HTML body. Common text, HTML, multipart, Base64, quoted-printable, UTF-8, ISO-8859-1, Windows-1252, GBK, GB2312, GB18030, and CP936 messages are supported on a best-effort basis.

  • Compatible embedded cid: images are read from the archive.
  • Remote http:// and https:// images are blocked by default, helping prevent a sender from learning that an archived message was opened.
  • A malformed message or unusual encoding should not prevent the rest of the archive from opening, though an individual message may display incomplete content.

Search

The message-list search field searches subject and sender for all users.

Full-text Search is a Lifetime Pro feature. Its local index covers message text, address fields, and attachment names. It builds in the background, shows progress, can be cancelled, is associated with the selected archive, and is discarded automatically when the source file changes.

Attachments and Exports

You can preview compatible attachments with Quick Look. Lifetime Pro includes saving attachments to Files; exporting all attachments from a message or archive; exporting an email as EML or PDF; and Advanced Details such as MIME structure and raw headers.

When several attachments are exported, they are processed one at a time. Duplicate filenames are safely renamed, for example report.pdf and report (2).pdf. The iOS Share sheet lets you choose the export destination; handle exported email data appropriately.

Recent Files

Recent Files retains a reference so that you can reopen an archive quickly. Removing an entry removes only that reference from MBOX File Viewer; it never deletes the original archive from Files, iCloud Drive, or another provider.

If the original is moved, renamed, deleted, or its access is revoked, select it again in the file picker to restore access.

Lifetime Pro and Restoring Purchases

Lifetime Pro is a one-time, non-consumable in-app purchase, not a subscription. It is associated with the Apple Account used for the purchase, subject to Apple’s policies.

  1. Open Settings in MBOX File Viewer.
  2. Tap Restore Purchases.
  3. If iOS asks, sign in with the Apple Account used for the original purchase.

If a product is temporarily unavailable, check your network connection and try again later. Apple’s purchase support and refund process applies to purchase, billing, and refund questions.

Troubleshooting

This file doesn't appear to be a valid MBOX archive

The selected file is not recognized as an MBOX archive or may be incomplete. Confirm that the export finished before opening it.

No email messages were found in this file

The file is readable but does not contain recognized MBOX message separators. Try exporting the mailbox again from its original mail application.

A message looks garbled

Older messages can use uncommon or malformed encodings. Try plain-text view if available. Common Chinese encodings are supported on a best-effort basis, but every legacy message cannot be guaranteed to render correctly.

An image is missing from an HTML message

Internet-hosted images are intentionally blocked. Supported inline images can display when included in the original archive through a cid: reference.

The app is not shown in another app’s Open in list

Save the attachment to Files first, then use Open MBOX File in MBOX File Viewer. Some third-party apps do not expose every installed document viewer in their sharing interface.
