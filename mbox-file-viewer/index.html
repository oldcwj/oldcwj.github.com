About MBOX File Viewer

MBOX File Viewer opens, searches and exports MBOX email archives locally on iPhone and iPad. No email account, cloud upload, IMAP or POP3 connection is required.

Key Features

  • Open MBOX email archives from Files and document providers
  • Read plain-text and supported HTML email locally
  • Search subjects and senders
  • Build an optional local full-text search index with Lifetime Pro
  • Preview compatible attachments and export EML or PDF files
  • Block remote HTML email images and web requests by default

Private, On-Device Archive Viewing

Your MBOX archive is read on your iPhone or iPad. The app does not require an email account, Gmail sign-in, cloud upload, IMAP or POP3 connection.

Open Large Archives with Progress

The app scans archives in small chunks and builds a lightweight message index, so it does not need to load every message body into memory at once.
