About Jar Runner

Jar Runner lets you run compatible JAR files, Java applications, Swing apps and supported J2ME software on Android.

Jar Runner was previously known as Jre4Android.

Key Features

  • Run JAR files on Android
  • Run .class files
  • Java command-line mode
  • Java Swing GUI support
  • J2ME app support
  • Java runtime on Android
