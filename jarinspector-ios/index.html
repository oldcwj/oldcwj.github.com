About JAR DLL EXE File Viewer

JAR DLL EXE File Viewer is an offline iPhone and iPad tool for browsing Java archives, reviewing manifests and classes, and inspecting EXE and DLL file structure.

Previously known as JarInspector: JAR Viewer.

Key Features

  • Open JAR, ZIP, CLASS, DLL and EXE files
  • Browse Java archives and resources
  • View MANIFEST.MF metadata
  • Decompile supported Java classes
  • Inspect PE headers and structure
  • Process files locally
