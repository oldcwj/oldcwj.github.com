File Viewer FAQ

Short answers about viewing technical file formats on iPhone and iPad.

Can I open JAR files on iPhone?

Yes. JAR DLL EXE File Viewer can browse JAR archive contents, including supported manifests, CLASS files and resources. It does not run JAR applications.

Can iPhone open DLL files?

The app can inspect DLL file structure locally, but iPhone and iPad do not execute Windows DLL files.

Can I view EXE files on iPhone?

The app can review available PE headers and file structure details, but it does not run Windows EXE programs.

Can I view Java CLASS files on iPhone?

You can inspect Java CLASS files and view supported decompiled Java output.
