About JarInspector - JAR Viewer

JarInspector is a JAR file opener and viewer for iPhone and iPad that browses Java archives, reads MANIFEST.MF metadata and previews decompiled class files locally.

Key Features

  • Open JAR and ZIP archives
  • Browse files inside Java archives
  • View MANIFEST.MF metadata
  • Inspect Java class files
  • Preview decompiled Java source
  • Process files locally
