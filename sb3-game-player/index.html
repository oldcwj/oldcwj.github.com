Open and play .sb3 files on iOS

SB3 Game Player lets you import Scratch-compatible .sb3 project files from the Files app and play them directly on iPhone or iPad. Projects are processed locally, making the app useful for offline playback and personal project testing.

SB3 Game Player is an independent application and is not affiliated with, endorsed by, or sponsored by the Scratch Foundation or MIT.

Key features

  • Open .sb3 project files
  • Play projects on iPhone and iPad
  • Import from the Files app
  • Process projects locally
  • Use projects offline
  • Simple full-screen playback
