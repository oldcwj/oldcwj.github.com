About SB3 File Opener & Player

SB3 File Opener & Player opens and plays Scratch-compatible .sb3 projects locally on iPhone and iPad, with project information, resource browsing and optional Pro controls and export.

Previously known as SB3 Game Player.

Key Features

  • Open .sb3 project files
  • Play projects on iPhone and iPad
  • View project information and resources
  • Import from the Files app
  • Use projects offline
  • Optional Pro controls and resource export
