Import, open and play Scratch-compatible SB3 project files on an Android phone or tablet.

Open a Scratch SB3 file on Android

SB3 File Opener & Player helps you select an .sb3 project from device storage and play it on Android. It is designed for users who receive an SB3 file by download, cloud storage, messaging or USB transfer and want a simple mobile playback workflow.

Key features

  • Open .sb3 project files
  • Play projects on Android phones and tablets
  • Import files from device storage
  • Browse recently opened projects
  • Use locally saved projects offline
  • Simple project playback controls

How to get started

Follow the step-by-step guide for choosing a file, opening the project and troubleshooting common import problems.
