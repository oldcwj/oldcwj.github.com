How to Open and Play Scratch SB3 Files on Android

Use SB3 File Opener & Player to import an .sb3 project from Android storage and play it on your phone or tablet.

What is an SB3 file?

An SB3 file stores a project created for Scratch 3, including its project data, costumes and sounds. If an .sb3 file is saved on your Android device, it normally needs a compatible player rather than a document or video app.

Steps to open an SB3 file on Android

  1. Download or copy the .sb3 file to your Android phone or tablet.
  2. Install and open SB3 File Opener & Player.
  3. Tap the option to open or import an SB3 project.
  4. Use the Android file picker to select your project.
  5. Wait for the assets to load, then start the project with the player controls.

Download SB3 File Opener & Player on Google Play

If the SB3 file does not open

  • Confirm that the filename ends in .sb3.
  • Download the file again if it is incomplete or corrupted.
  • Make sure enough device storage is available for project assets.
  • Try a smaller project to check whether a specific extension or asset is incompatible.
  • Do not rename an unrelated ZIP file to .sb3; changing an extension does not convert the file.

Can an SB3 file run offline?

A project that has already been saved on the device can generally be imported and played locally. A project that requests external resources or uses an unsupported extension may still behave differently from the original editor.

Opening SB3 files on iPhone or iPad

Apple users can follow the separate iOS and iPadOS SB3 guide and download SB3 Game Player from the App Store.
