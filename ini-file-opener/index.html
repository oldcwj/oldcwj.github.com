About INI File Opener & Editor

INI File Opener & Editor lets Android users open, edit, search, format and save INI configuration files, including common CONF, CFG and properties files.

Key Features

  • Open .ini files on Android
  • View and edit sections, keys and values
  • Search configuration text
  • Format INI content
  • Save or export a copy
  • Back up before saving
